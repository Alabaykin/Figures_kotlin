# Figures

Практическая работа по ООП на Kotlin. 

Реализованы классы фигур `Rect`, `Circle`, `Square`, наследующие абстрактный класс `Figure`. 
Для фигур реализованы интерфейсы `Movable` и `Transforming` (масштабирование и поворот на 90 градусов вокруг заданной точки).

### Демонстрация работы

Вывод программы `Main.kt`:

```
Rect(x=0, y=0, w=4, h=2)
Rect(x=3, y=-2, w=2, h=4)
Area: 32.0

Circle(x=1, y=1, r=5)
Circle(x=0, y=2, r=10)
Area: 314.15927

Square(x=2, y=2, side=3)
Square(x=4, y=-1, side=9)
Area: 81.0
```
